# Project Planning Toolkit

Take a project of your own from a hunch to something made: spin for a way in, write a brief, get research methods, try things out, plan, and look back.

Adapted from the Project Planning Toolkit & Workbook by Alejandro Ramos Saavedra. The moves come from [Actionary](https://operations.ramos-saavedra.com).

- Live (test season): https://toolkit.ramos-saavedra.com, linked from the ramos-saavedra.com homepage since 2026-10-18
- The page is one self-contained file: `site/index.html`. GitHub Pages publishes the `site/` folder.
- Open to search engines since 2026-10-18: description, canonical, share tags (`site/share.png`), favicon, `robots.txt` and `sitemap.xml`. `src/build_site.py` writes all of these.
